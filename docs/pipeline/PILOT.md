# Bounded Bacolor pilot

Run on 15 October 2026 (Asia/Singapore). The [official release calendar](https://docs.overturemaps.org/release-calendar/) identifies `2026-09-23.1` as the current release; the next proposed release is 21 October. The [current Places Guide](https://docs.overturemaps.org/guides/places/) documents `taxonomy.hierarchy` and `basic_category`; deprecated `categories` was removed in September 2026.

`pilot-overture.json` contains 20 actual public-data records retrieved from that release, within bbox `120.64,14.985,120.665,15.01`. The remote Parquet query projects only relevant metadata, pushes bbox and food taxonomy predicates to DuckDB, and limits output to 20. The food predicate additionally requires `restaurant` or `casual_eatery`, excluding alcohol-only establishments. No full dataset was downloaded. No database was modified and no paid APIs were called.

Examples include Keni Bale Grill & Restaurants, Cindy's Bakery Bacolor Branch, Hooo Taho Bacolor Branch, Cuffy Cafe, and Minute Burger. These are source records, not independently verified operating businesses. Confidence ranges from roughly 0.128 to 0.949; low scores remain visible as source confidence and are not promoted to verified facts. Phone, website, address and provider fields are retained where supplied. Prices, cuisines, dietary claims and images remain unknown. Names retain source text including any source encoding defects.

Every sampled record carries `meta` and `Overture` provider entries licensed `CDLA-Permissive-2.0`; the raw per-provider `sources` objects are retained. General Overture Places licensing also includes Apache-2.0 for some other providers; [attribution requirements](https://docs.overturemaps.org/attribution/) must be reviewed for a public distribution. OSM attribution remains separately `© OpenStreetMap contributors; ODbL 1.0`; combining databases may carry derivative-database obligations, so preserve source provenance.

One bounded OSM Overpass POST was attempted with a maximum 20 outputs and 25-second provider timeout. `overpass-api.de` returned HTTP 406. No retry or failover was attempted after the provider's busy response. A successful actual raw OSM pilot could not be recorded in this run; existing normalized OSM fixtures and contract tests remain separate from this live result.

Importer defaults to dry run. Install `scripts/requirements-import.txt`, then run `python scripts/import_overture.py` to inspect query and parameters. `python scripts/import_overture.py --fetch` executes this local-only pilot. Bounds above 0.02 square degrees, malformed release identifiers, nonfinite coordinates and limits above 100 are rejected. Output changes require `--output`; no credentials or database options are accepted. The release is pinned for reproducibility and must be reviewed before its public 60-day retention window expires.

Verification: Python importer tests cover bounds, caps and current taxonomy projection; Vitest covers normalization, unknown values, attribution, stable deduplication, same-source branches and conflicts. Same-source distinct IDs are preserved even at the same address; cross-source merging requires equal normalized full names, equal nonempty addresses and coordinates within 30 metres. Conflicting facts are retained for human review, and unapproved hard constraints remain unknown.
